# 🌟 Elan Boutique | Dashboard de Vendas

Este é o seu novo sistema de gestão de vendas. Ele foi projetado para ser rápido, bonito e funcional.

## Como começar
Basta abrir o arquivo **index.html** no seu navegador.

## Funcionalidades
- Cadastro de vendas com categoria, data e preço.
- Dashboard com faturamento total e ticket médio.
- Gráfico de desempenho semanal.
- Filtros por categoria.
- Salvamento automático (Nada se perde!).
